# Модуль CRM: клиенты, КП, скидки, продажи

Два новых файла для проекта:

- **`crm_db.py`** — база данных SQLite (`crm.db`, создаётся автоматически при первом запуске рядом с `app.py`). Хранит клиентов, КП, позиции КП и продажи.
- **`crm_ui.py`** — готовые Streamlit-блоки для вкладок "Клиенты", "КП", "Продажи" и блок сохранения текущего расчёта.

Зависимостей добавлять не нужно — `sqlite3` входит в стандартную библиотеку Python.

## Что реализовано

1. **Карточка клиента**: телефон, email, ИНН, КПП, ОГРН, адрес, банк, директор. Ввод ИНН → кнопка "Подгрузить данные клиента" → если клиент уже есть в базе (сохранён ранее) — реквизиты подгружаются автоматически; если нет — можно вставить текст карточки партнёра, и `req_parser.py` (уже используется в вашем `app.py`) распарсит реквизиты.
2. **Состав КП**: тип товара (Кран / Траверса / Кран + траверса / Тали / Прочее), конкретная модель, флаг "с монтажом / без монтажа", город доставки — всё фиксируется в таблице `quotes`.
3. **Ручная скидка**: слайдер 0–30% (рекомендация в подсказке 5–10%), сумма и итог пересчитываются вживую, фиксируются в базе при сохранении. Скидку можно изменить и позже — через вкладку "КП" → "Изменить скидку".
4. **База проданных товаров**: при переводе статуса КП в "Продано" запись автоматически попадает в таблицу `sales` — дата, товар, цена, город, скидка. Вкладка "Продажи" показывает сводку (кол-во, сумма, средняя скидка) и таблицу с выгрузкой в CSV.

## Как подключить к вашему `app.py`

Добавьте импорт в начало файла:

```python
import crm_db
import crm_ui
```

Найдите место, где у вас уже посчитана итоговая сумма КП (переменная `total` в `app.py`, строка со `spec_df["Сумма"].sum()`), и оберните существующий интерфейс во вкладки:

```python
tab_calc, tab_clients, tab_quotes, tab_sales = st.tabs(
    ["Расчёт КП", "Клиенты", "КП и скидки", "Продажи"]
)

with tab_calc:
    # ... весь ваш существующий код расчёта КП без изменений ...
    # в конце, после того как известны total, series/capacity, include_montage:
    crm_ui.render_save_quote_block(
        base_total=total,
        product_type="Кран",  # или "Траверса" / "Кран + траверса" — определяется вашей логикой выбора
        product_model=f"{series} {capacity}кг {boom}м",
        include_montage=include_montage,
        spec_lines=spec_df.to_dict("records"),
    )

with tab_clients:
    crm_ui.render_customers_tab()

with tab_quotes:
    crm_ui.render_quotes_tab()

with tab_sales:
    crm_ui.render_sales_tab()
```

Для модуля траверс (`traverse-3.py`) передавайте `product_type="Траверса"` и `product_model=selection.code` аналогично.

## Структура базы данных (crm.db)

- `customers` — клиенты (ИНН уникален, повторный ввод того же ИНН обновляет карточку, а не создаёт дубликат).
- `quotes` — каждый сформированный КП: сумма без скидки, скидка %, сумма скидки, итог, статус (`draft` / `sent` / `won` / `lost`), город доставки, монтаж.
- `quote_items` — построчный состав каждого КП (для истории — что именно входило).
- `sales` — денормализованная витрина продаж, наполняется автоматически при переводе КП в статус "Продано".

## Автоподгрузка реквизитов по ИНН (DaData)

Кнопка "🔍 Подгрузить данные клиента по ИНН" подтягивает карточку:

1. Сначала ищет клиента в локальной базе `crm.db`.
2. Если не найден — делает запрос к **DaData Suggestions API**
   (`https://suggestions.dadata.ru/suggestions/api/4_1/rs/findById/party`).
3. Если передан текст карточки партнёра — дополняет поля
   (телефон, email, банк) через `req_parser.py`.

### Настройка токена DaData (бесплатно, 10 000 запросов/день)

1. Зарегистрируйтесь на [dadata.ru](https://dadata.ru/api/) — дают токен бесплатно.
2. Скопируйте ваш **API-ключ (токен)** в личном кабинете.
3. Создайте файл `.streamlit/secrets.toml` в корне проекта:

   ```toml
   DADATA_TOKEN = "ваш-токен"
   ```

   Для Streamlit Cloud: **Settings → Secrets** → вставьте ту же строку.
4. Перезапустите приложение.

Без токена кнопка всё равно работает, но подгружает только тех клиентов,
которые уже есть в локальной базе (API DaData возвращает 401).

## Файл базы

`crm.db` создаётся в той же папке, где лежит `app.py`. Он не нужен в git/деплое — исключите его в `.gitignore`, если используете git; при первом запуске на новом сервере файл создастся автоматически пустым.
