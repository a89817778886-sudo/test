# ЛКС · Генератор КП и Договора поставки

Streamlit-приложение для быстрого подбора консольных кранов **ЛКС71 / ЛКС73 / ЛКС77 / ЛКС78**, формирования красивого коммерческого предложения (**DOCX** и **PDF**) и договора поставки.

## Что умеет

- Подбор крана по серии → грузоподъёмности → длине стрелы → высоте (со строгим фильтром допустимых комбинаций из паспорта логики).
- Автоматическая комплектация: таль (OCALIFT / R-Tech), поперечная тележка под таль, кабельные тележки, начальный подвес, кабель питания.
- Опциональный пакет **электрификации** (ЛКС71/73, 250/500/1000 кг).
- Опциональный **монтаж и ПНР** (отдельный блок, без НДС, отдельным договором).
- Живой пересчёт итога с НДС 22 %, предоплата / остаток.
- Экспорт **КП в DOCX и PDF** — с фирменным титулом, фото крана и тали, таблицами характеристик, спецификацией, условиями и подписью.
- Экспорт **Договора поставки в DOCX** на базе шаблона ООО «ЛКС» + Приложение № 1 «Спецификация» с полным юридическим текстом и реквизитами покупателя.

## Быстрый старт (локально)

```bash
git clone <ваш-репозиторий>
cd lks-kp-app
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере на `http://localhost:8501`.

## Деплой на Streamlit Community Cloud

1. Залейте репозиторий на GitHub (можно приватный).
2. Зайдите на [share.streamlit.io](https://share.streamlit.io) → **Create app**.
3. Укажите:
   - **Repository** — ваш репозиторий,
   - **Branch** — `main`,
   - **Main file path** — `app.py`.
4. Нажмите **Deploy**. Приложение соберётся за 1–3 минуты.

## Правила логики (кратко)

**Грузоподъёмность и длины стрел ЛКС71/73**

| Г/п, кг | Длина стрелы |
|---:|---|
| 80 | 3–5 м |
| 125 | 3–7 м |
| 250 | 3–8 м |
| 500 | 3–8 м |
| 1000 | 3–6 м |

**ЛКС77/78** — г/п 150 или 300 кг, длина стрелы 2/3/4 м, высота (для ЛКС78) 3–6 м.

**Тали**
- ЛКС71/73: OCALIFT (1 или 2 скорости), R-Tech (8/2 м/мин).
- ЛКС77/78: только R-Tech; при высоте подъёма до 3 м доступен вариант с ручным контролем груза.

**Поперечная тележка под таль**
- OCALIFT: 125–500 кг → 523, 1 т → 533.
- R-Tech: 80 кг → 513.RC59, 125–500 / 300 кг → 521, 1 т → 533.

**Кабельные тележки (только ЛКС71/73)** — `321.050.RC74.65х54`, количество = длина стрелы − 1. Начальный подвес `327.050.RC74.65х54` — 1 шт.

**Электрификация** — только ЛКС71/73 и только для 250 / 500 / 1000 кг.

**НДС 22 %. Предоплата по умолчанию 70 % / 30 %.**

## Обновление прайсов

Прайсы можно как заменить в папке `prices/`, так и **загрузить через сайдбар приложения**. Загруженный файл имеет приоритет над лежащим рядом.

## Реквизиты Поставщика

Реквизиты **ООО «ЛКС»** зашиты в `app.py` в константе `SUPPLIER`. Если они изменятся — правьте только этот блок.
